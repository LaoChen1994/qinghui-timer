# 0.2.2 交付验证报告

验证日期：2026-10-03。开发与桌面实测环境为 Apple Silicon Mac。

## 已交付功能

名称输入；40／60／90 分钟预设与 1～1440 整数分钟自定义周期；多怪物独立倒计时；击杀后单独重置；剩余 3 分钟和到点提醒弹框；系统通知权限入口；本地保存与重启恢复。

当前版本的精简窗口为 320×600 的竖条：隐藏品牌标题、统计和说明，只显示怪物名称、倒计时、细进度条与单条重置按钮，保留置顶／展开按钮及窗内小提醒条。完整窗口尺寸／最大化状态仍可恢复。

新增 JSON 导入／导出，分享名称、周期、上次重置毫秒时间戳与刷新毫秒时间戳；导入不会从打开文件时重新起算。导入预览按名称匹配，不同名称新增，同名逐条选择覆盖或保留，本地同名多条时指定覆盖目标。整批校验、统一确认并原子保存；失败不改当前记录。已到期记录显示「已刷新」，不补发历史提醒，重复导入完全相同记录保留原提醒状态。

计时按照绝对刷新时间计算，界面每秒读取 Rust 后台状态。到点保留「已刷新」，由用户手动重置下一轮；同名记录互不影响。提醒状态和待确认提醒一起保存，避免重启重复生成已处理的提醒。

## macOS 实际窗口验证

原有计时和提醒功能在 0.1.0 打包后的 Tauri 应用中验证以下流程（本轮未改变计时引擎）：

1. 创建 40 分钟和 1 分钟两个计时器，检查真实倒计时推进和本地保存。
2. 检查短周期的「即将刷新」提醒弹框，确认后不持续重复弹出。
3. 最小化窗口，等待到点，再恢复窗口，检查「已经刷新」弹框与状态。
4. 退出应用，启动通用版，检查长周期继续按原刷新时刻倒计时，已确认的到点提醒不再次弹出。
5. 单独重置长周期，确认重新显示 40:00，另一条已刷新记录不受影响。
6. 通过删除确认弹框清理两条测试记录，交付窗口回到空列表。

以上均通过。系统通知权限显示已开启，后台发送调用未报告错误；未将观察到系统通知横幅列为实测通过项。

0.1.0 精简模式另做过以下实测，均通过（当时尺寸为 320×420，本轮调整为 320×600）：

1. 从完整界面切为精简空窗口，窗口确实缩小为 320×420；可展开添加记录。
2. 创建 40 分钟和 1 分钟两条记录后切入精简模式，显示名称、倒计时与重置按钮。
3. 图钉开启与取消置顶均调用成功，按钮状态对应变化。
4. 预提醒显示为小提示条；保留提示条时重置另一只怪物成功，短周期倒计时继续。
5. 确认预提醒，实际等待到点，再次出现「已经刷新」提示条，卡片变为「已刷新」。
6. 确认到点提醒并展开，继续显示同一批记录。窗口放大后切换精简模式，再展开，恢复的截图尺寸与切换前一致。
7. 删除本次创建的两条测试记录，最后保留精简空窗口，置顶关闭。

0.2.0 的导入／导出功能使用打包的 macOS 通用版做过以下实测：

1. 创建 40／60 分钟两条测试记录，通过原生保存对话框导出 JSON，核对时间戳与本地记录逐项一致，文件不包含本地编号或提醒状态。
2. 通过原生打开对话框导入四条记录：覆盖一条为 90 分钟周期、保留一条、新增一条剩余约 30 分钟记录和一条已到期记录。结果为新增 2／更新 1／保留 1，保存的时间戳逐项符合选择。
3. 切为 320×600 竖条，截图为 Retina 640×1200；没有大标题／统计／说明，显示名称、倒计时、预计刷新和重置按钮。单独重置一条后核对其余三条时间戳保持不变。
4. 退出并重新打开，四条导入记录及重置时间恢复，已到期记录不重复弹提醒；无效 JSON 报错且不改原有记录。
5. 发现连续打开原生文件选择器时按钮可能禁用。增加对主窗口的焦点激活后，在打包的调试版本连续验证取消选择、坏文件报错、再次进入有效文件预览及取消、导出保存；全部可正常操作，数据保持不变。修复已纳入最终安装包，并在最终通用版中再次验证连续取消导出、坏文件报错、打开有效文件预览及取消，全程正常。
6. 通过应用的删除确认清理本轮创建的四条测试记录，交付数据回到空列表。

没有在真实游戏窗口上测试遮挡效果。独占全屏能否同时显示计时器取决于游戏和系统；建议使用窗口化或无边框模式。

Windows 安装程序在 macOS 上使用 `cargo-xwin` 交叉编译生成；NSIS 安装程序引导部分为 32 位格式，所安装的应用程序为 x64。系统通知应使用安装后的程序验证，不能用裸 EXE 的结果替代。

两个安装包均未使用开发者证书签名，macOS 尚未公证。跨设备首次打开可能受系统安全策略限制。当前版本请保持应用运行；最小化持续计时，退出、关机或休眠期间无法发送提醒，重新运行后恢复倒计时及有效的到点提醒。

`.github/workflows/build.yml` 已提供 Windows/macOS 原生构建流程，但本项目没有连接远端仓库，本次未运行远端 CI。不能以流程文件存在代替 Windows 实机测试。
